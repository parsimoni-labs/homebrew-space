# homebrew-space

Homebrew tap.

## Installation

```bash
brew tap parsimoni-labs/space
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| `space` | SpaceOS CLI: build and boot SpaceOS VMs |

## Usage

```bash
# Install pre-built binaries
brew install space

# Or build from source
brew install --HEAD space
```
