# homebrew-space

The Homebrew tap for `space`, the SpaceOS CLI.

*Pre-release: the first `space` bottle lands here with the 1.0
release.*

## Installation

```bash
brew tap parsimoni-labs/space
brew install space
```

## Formulas

| Formula | Description |
|---------|-------------|
| `space` | SpaceOS CLI: build and boot SpaceOS VMs |
